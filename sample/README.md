# Sample book sources

These are the aligned source files for `app/sample/the_spiders_thread.html`.

- **Japanese:** 芥川龍之介「蜘蛛の糸」(1918), which is in the public domain. The text comes from [Aozora Bunko](https://www.aozora.gr.jp/cards/000879/card92.html) (底本：「芥川龍之介全集2」ちくま文庫). I made three changes:
  - Aozora's input notes were removed.
  - The external character ※［＃「特のへん＋廴＋聿」］ was replaced with 犍.
  - Implicit ruby was rewritten in the explicit `｜base《reading》` form.
- **English:** my own translation, aligned one paragraph per Japanese paragraph.

Each `NNN - …` pair is one chapter. The first line is the chapter title, and paragraphs are separated by blank lines. Paragraph *n* of the English file translates paragraph *n* of the Japanese file.
